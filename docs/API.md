# KisanSathi AI — REST API Documentation

All endpoints are hosted under prefix `/api/v1`. Interactive Swagger documentation is automatically generated by FastAPI at `http://127.0.0.1:8000/docs`.

---

## 1. System Endpoints

### `GET /api/v1/health`
Returns system status and version.
```json
{
  "status": "healthy",
  "service": "KisanSathi AI",
  "version": "1.0.0",
  "environment": "development"
}
```

### `GET /api/v1/config`
Returns frontend runtime configuration, active provider flags, and supported languages.
```json
{
  "project_name": "KisanSathi AI",
  "version": "1.0.0",
  "ai_provider": "demo",
  "weather_provider": "demo",
  "is_demo_mode": true,
  "supported_languages": ["mr", "hi", "en"],
  "max_upload_size_mb": 5
}
```

## 2. Dashboard

### `GET /api/v1/dashboard`
**Query Parameters**:
- `location` (optional string): e.g. "Baramati, Pune"
- `district` (optional string): e.g. "Pune"
- `state` (optional string): e.g. "Maharashtra"

Returns integrated farmer profile, weather snapshot, registered fields count, prioritized farming tasks, and recent conversations.

## 4. Crop Health Checker

### `POST /api/v1/crop-assessments`
**Content-Type**: `multipart/form-data`
**Form Fields**:
- `crop_type` (required string, min 2 chars)
- `symptoms` (required string, min 3 chars)
- `growth_stage` (optional string)
- `language` (optional string, "mr" | "hi" | "en")
- `image` (optional file, max 5MB, JPG/PNG/WEBP)

**Response**:
Returns assessment result with possible causes, confidence level, immediate IPM actions, monitoring checklist, expert escalation guidelines, and safety disclaimer. `vision_processed` is true only when a configured Gemini vision model successfully analyzes the supplied image; otherwise, results use local text/rule-based guidance. Image analysis is preliminary and cannot confirm root-zone soil moisture or establish a definitive diagnosis.

## 5. Weather & Farming Advisory

### `GET /api/v1/weather`
**Query Parameters**:
- `location`, `district`, `state`

Returns temperature, humidity, wind, rainfall probability, operational farming advisory (irrigation, spraying windows, harvesting), and 5-day forecast.

## 6. Government Schemes

### `GET /api/v1/schemes`
**Query Parameters**:
- `category` (optional: "Income", "Insurance", "Irrigation")
- `search` (optional search query)

### `GET /api/v1/schemes/{scheme_id}`
Returns details, required documents, application steps, and verified official link for a single scheme.

### `POST /api/v1/schemes/eligibility`
**Request Body**:
```json
{
  "scheme_id": "pm-kisan",
  "land_holding_acres": 2.5,
  "category": "Small/Marginal",
  "state": "Maharashtra",
  "has_aadhaar_linked_bank": true,
  "has_7_12_extract": true,
  "has_irrigation": true
}
```
**Response**:
Returns calculated eligibility percentage, detailed criterion-by-criterion explanation, missing document alerts, and legal notice.

## 7. My Fields & Farmer Diary

### `GET /api/v1/fields`
Returns all registered fields with nested observations.

### `POST /api/v1/fields`
Creates a new field. Status code: 201 Created.

### `GET /api/v1/fields/{field_id}`
Returns a single field.

### `PATCH /api/v1/fields/{field_id}`
Updates editable properties (crop, growth_stage, area, notes).

### `DELETE /api/v1/fields/{field_id}`
Deletes field and cascaded observations. Status code: 204 No Content.

### `POST /api/v1/fields/{field_id}/observations`
Adds a dated observation entry with optional photo URL. Status code: 201 Created.

### `GET /api/v1/fields/{field_id}/observations`
Returns chronological observations for the given field.
